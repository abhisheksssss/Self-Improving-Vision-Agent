1. Executive Summary & Architectural Mission

Autonomous Graphical User Interface (GUI) computer-use agents must reliably bridge high-level natural language human intent with complex desktop operating systems and browser environments. While frontier Vision-Language Models (VLMs) have demonstrated zero-shot multimodal reasoning, deploying them as raw coordinate clickers (e.g. click(x, y)) leads to coordinate drift, open-loop execution failure loops, prohibitive inference costs, and zero cross-session memory.

SIVAC (Self-Improving Vision Agent for Autonomous Computer Use) is designed as a resilient, closed-loop cybernetic system. Rather than treating computer operation as an open-loop script, SIVAC executes an 8-stage deterministic control loop:

SIVAC Cybernetic Control Loop:
Observe → Perceive → Retrieve → Plan → Act → Verify → Diagnose/Recover → Reflect/Learn

2. System Architecture

The system architecture decouples perception, orchestration, action execution, and memory storage into modular subsystems communicating via strongly typed Pydantic contracts.

4.2 Dual-Layer Memory Specification

Layer 1 (Relational Audit Store): SQLite 3 with SQLAlchemy 2.0 ORM provides full transactional guarantees, foreign-key cascade deletions, and millisecond query times for debugging and replaying action traces.
Layer 2 (Semantic Skill Memory): ChromaDB vector store running locally in-process without cloud infrastructure. It indexes past failure contexts and application behaviors using all-MiniLM-L6-v2 embeddings. During task initialization, semantic search retrieves relevant heuristic rules (e.g. "In Excel, pressing ESC is required before selecting ribbons") and appends them to the system prompt.

5. Technology Stack Selection & Rationale

Subsystem Selected Tech Alternatives Considered Rationale & Technical Tradeoff
Core Language Python 3.12 Python 3.10, Node.js, Rust Python provides first-class support for LangChain/LangGraph, OpenCV, PyTorch/ONNX, and OS automation libraries. 3.12 delivers significant runtime execution speedups.
Package Manager uv + hatchling Poetry, Pipenv, Conda 10-100x faster package resolution and installation. Pure PEP 621 compliance with universal uv.lock determinism.
Orchestration LangGraph AutoGen, CrewAI, Raw Loops First-class cyclic graph execution with deterministic state rollback, human-in-the-loop breakpoints, and conditional failure recovery.
VLM Providers Groq Qwen-VL & Gemini Flash GPT-4o, Claude 3.5 Sonnet Sub-500ms inference on Groq and Google AI Studio free tier allows continuous visual closed-loop cycles without incurring $50+/hr API bills.
Screen Capture mss + Pillow OpenCV native, PyGetWindow Sub-15ms multi-monitor buffer capture with zero external DLL dependencies.
Action Drivers PyAutoGUI + Playwright + pywinauto Native C Win32 hooks Seamless bridging between browser DOM elements and native Windows OS desktop controls with built-in cursor corner safety kill-switches.
Relational DB SQLite + SQLAlchemy 2.0 PostgreSQL, DuckDB Zero setup, zero-daemon file portability, fully ACID compliant for desktop standalone deployment.
Vector DB ChromaDB Pinecone, Milvus, Qdrant Pure Python embedded vector database running in-process; no Docker container or network round-trips required.
API & UI FastAPI + React (Vite) Flask, Streamlit, Gradio Streamlit/Gradio suffer from heavy re-render latency during 30fps screen streaming. FastAPI WebSockets + React provides fluid, instant updates.
